# 番茄伴伴 🍅

> 一只住在桌面上的蔬菜伙伴，把「我要做什么」变成一颗颗真正完成的番茄。

番茄伴伴是一款原生 macOS 悬浮桌宠：它始终轻巧地待在桌面一角，陪你规划、专注、休息和复盘。没有账号、没有云端，计划与总结只保存在本机。

在桌宠上点击右键，选择 **选择蔬菜形象**，即可随时更换伙伴。选择会自动保存，下次启动仍然是熟悉的它。

## 三分钟上手

1. 打开 `番茄伴伴.app`，桌宠会出现在桌面右下角。
2. 单击桌宠，写下这一颗番茄要完成的事情；默认专注 50 分钟。
3. 想换时长？开始前双击桌宠，输入分钟数后按 `Enter`。
4. 专注结束后桌宠会跳动提醒。点击它，进入 10 分钟休息。
5. 休息期间点击 **总结 · 规划下一颗**，在同一页回顾这一颗并安排下一颗。

第一次打开如果 macOS 提示来自未识别开发者，请在 Finder 中右键应用并选择 **打开**。

## 一颗番茄的完整仪式

### 1. 规划：只选最重要的三件事

每颗番茄最多放 3 项清单。数量有限，反而更容易明确「这一段时间真正要推进什么」。休息时尚未完成的项目会自动带到下一颗，不会因为总结而消失。

### 2. 专注：把进度留在桌面上

专注进行中，点击 **清单** 即可展开完整任务：

- 勾选完成项后，文字会划线保留，进度一眼可见。
- 点击 **灵感**，随手记下最多 5 条突然冒出的想法，不必离开当前任务。
- 单击桌宠可暂停或继续；按住拖动可把它放到顺手的位置。
- 鼠标停在目标卡片上，可查看被折叠的完整计划。

### 3. 休息：真的离开屏幕十分钟

桌宠会提醒你站起来、走一走、看看远处。休息倒计时内就可以开始填写总结，不需要等到最后一秒。

### 4. 复盘：让清单替你写总结

已完成与待继续的清单会自动进入总结草稿，减少重复输入。总结与下一颗规划放在同一个页面，可以上下对照；灵感也能一键加入下一颗计划，加入后会从灵感栈中移出。

右键选择 **生成今日总结**，还可以自动汇总当天的完成项、待继续项和复盘内容，编辑后一键复制。

## 常用操作

| 操作 | 效果 |
| --- | --- |
| 单击桌宠 | 开始、暂停、继续或进入休息 |
| 双击桌宠 | 开始前修改计划与专注时长 |
| 按住拖动 | 移动桌宠 |
| 点击「清单」 | 查看、编辑、勾选当前任务 |
| 点击「灵感」 | 专注中快速记录想法 |
| 右键桌宠 | 切换形象、查看总结、重置或退出 |
| `⌘A / ⌘C / ⌘X / ⌘V` | 在计划与总结中全选、复制、剪切、粘贴 |

## 安装与构建

系统要求：macOS 13 或更高版本，并安装 Xcode Command Line Tools。

```bash
git clone https://github.com/MidoKun-hub/tomato-companion-macos.git
cd tomato-companion-macos
chmod +x build.sh
./build.sh
open "build/番茄伴伴.app"
```

构建脚本会生成并临时签名应用，产物位于：

```text
build/番茄伴伴.app
```

若想固定在程序坞，可先把应用拖入 `/Applications`，启动后在程序坞图标上选择 **选项 → 在程序坞中保留**。

## 数据与隐私

- 任务、倒计时、灵感和总结使用 macOS `UserDefaults` 保存在本机。
- 应用不需要登录，不上传任何计划或总结。
- 退出再打开时，会恢复当前阶段、剩余时间与上次选择的蔬菜伙伴。

## 设计理念

番茄伴伴不追求把时间管理做得复杂。它只守住三个小原则：当前目标看得见、完成进度有仪式感、每次休息都顺手留下可复用的总结。把一天切成几颗小番茄，压力也会跟着变小一点。
